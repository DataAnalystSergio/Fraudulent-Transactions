# Fraudulent-Transactions
Proyecto de detección de transacciones fraudulentas en el mercado de capitales con Microsoft Fabric. Implementa arquitectura Medallion, modelo semántico, modelo de grafos (Graph), Agente de Datos con IA, análisis de anomalías basado en reglas de negocio y dashboard interactivo en Power BI para la gestión del riesgo financiero.
